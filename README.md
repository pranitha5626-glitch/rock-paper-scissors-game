# Rock Paper Scissors Game 

## About the Project
This is a simple Rock Paper Scissors game developed using Python. The user plays against the computer, and the computer randomly selects Rock, Paper, or Scissors.

The game continues until the user enters `Q` to quit.

## Technologies Used
- Python
- Random Module

## Features
- Play against the computer.
- Computer makes a random choice.
- Displays the computer's choice.
- Tracks user and computer wins.
- Allows the user to quit anytime by entering Q.

## Game Rules
- Rock beats Scissors.
- Paper beats Rock.
- Scissors beats Paper.
- Otherwise, the computer wins.

## How to Run
1. Clone this repository.
2. Open the project in VS Code.
3. Run the following command:

```bash
python main.py
```
